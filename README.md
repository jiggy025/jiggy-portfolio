## Architecture & Motion Engineering

- **Motion Engine:** [Lenis](https://github.com/darkroomengineering/lenis) for 60-120 FPS momentum inertia scrolling + [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) for pinned/stacked card transitions.
- **Styling:** Tailwind CSS with Smoked Obsidian & Crimson design tokens.
- **Accessibility:** Automatic degradation under `prefers-reduced-motion: reduce`.
- **Hosting:** Optimized for [Vercel](https://vercel.com) with immutable asset caching.
